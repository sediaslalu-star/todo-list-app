# Todo List App

A simple, responsive to-do list app with localStorage persistence.

## Features

- Add tasks
- Mark tasks as complete/incomplete
- Delete individual tasks
- Filter tasks by all/active/completed
- Clear completed tasks
- Automatically saves to the browser's `localStorage`

## Run locally

Open `index.html` in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — app structure
- `style.css` — styling
- `script.js` — app logic and localStorage behavior
